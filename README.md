This project aims at picking an appropriate and exhaustive dataset, solving challenges in the dataset, and developing convolutional neural network models with varying hyperparameters to classify traffic signs. This model is an integral component of modern vehicles that use this technology to make them ‘smart’. It could potentially alert the drivers of such modern vehicles to recognize the signs early on and thereby decrease the probability of accidents.





We aim at using a convolutional neural network as the fundamental machine learning model to classify traffic signs. We intend to use the German Traffic Sign Recognition Benchmark dataset to train, test and validate the input. This dataset contains 43 different traffic sign classes and a total of about 51,000 images. The dataset creators have already pre-cropped the images and labeled each of them. The German Traffic Sign Recognition Benchmark dataset is used for training and testing our models. This dataset contains 50000+ traffic sign images and these images are fed as pixel values to our CNN models that classify them into one of the 43 classes of traffic signs.
